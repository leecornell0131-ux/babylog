# 아기로그 앱 (0.2, 아이폰·갤럭시 웹앱)

수유·수면·기저귀와 이유식·체온·약·목욕 같은 다른 기록, 24시간 원형 차트, 주간 패턴, 성장곡선(WHO 기준), 기록 공백 확인, 분유량이 줄었을 때 확인 질문, AI에게 물어볼 자료 복사, 백업, 삐요로그 기록 불러오기, 가족 공유(선택)를 담은 웹앱이에요.
아이폰 Safari에서 "홈 화면에 추가"하면 일반 앱처럼 아이콘으로 열리고, 인터넷이 없어도 열려요. 운영비는 0원이에요.

## 설치하기

주소: https://leecornell0131-ux.github.io/babylog/

- **아이폰 (Safari)**: 위 주소를 열고 아래쪽 공유 버튼 > "홈 화면에 추가"를 누른 뒤, 홈 화면의 아기로그 아이콘으로 열어요.
- **갤럭시 (Chrome 또는 삼성 인터넷)**: 위 주소를 열고 오른쪽 위 메뉴(⋮) > "홈 화면에 추가" 또는 "앱 설치"를 눌러요.
- 기록은 각 휴대폰에 따로 저장돼요. 두 휴대폰의 기록을 합쳐 보려면 아래 가족 공유를 켜야 해요.
- 미리보기 링크(설치·오프라인 안 됨): https://claude.ai/artifact/NHU2eNHovaw66TdkfZ2qnR

## 삐요로그 기록 옮기기

삐요로그 PDF에서 뽑은 불러오기 파일(JSON)을 휴대폰에 저장한 뒤, 앱의 설정 > 불러오기(처음 화면이면 "백업·삐요로그 파일 불러오기")에서 그 파일을 고르면 돼요. 이미 기록이 있으면 지우지 않고 합쳐요. 같은 파일을 두 번 불러와도 기록이 두 번 생기지 않아요.

아기 기록은 이 공개 저장소에 올리지 않아요.

## 앞으로 할 일

### 1. 앱 업데이트

파일을 바꾸면 `sw.js`의 VERSION을 올려서 이 저장소 main에 올리면 1~2분 뒤 반영돼요. 설치한 앱은 한 번 껐다 켜면 새 버전이 열려요.

### 2. 배우자와 기록 공유하기 (선택, Firebase 무료 요금제)

카드 등록이 없는 무료 요금제(Spark)라 한도를 넘어도 돈이 나가지 않고 그날 동기화만 멈춰요.

1. https://console.firebase.google.com 에서 프로젝트를 만들어요 (Google Analytics는 꺼도 돼요). 요금제는 Spark 그대로 두고 **결제 수단을 등록하지 마세요.**
2. Build > Authentication > 시작하기 > 로그인 방법에서 **익명**을 사용 설정해요.
3. Authentication > 설정 > 승인된 도메인에 `leecornell0131-ux.github.io` 를 추가해요.
4. Build > Firestore Database > 데이터베이스 만들기. 위치는 `asia-northeast3 (서울)`, 프로덕션 모드로 만들어요.
5. Firestore > 규칙 탭에 이 폴더의 `firestore.rules` 내용을 통째로 붙여넣고 게시해요.
6. 프로젝트 설정(톱니바퀴) > 내 앱 > 웹 앱 추가(`</>`) 를 눌러 나오는 `firebaseConfig` 값(apiKey, authDomain, projectId, appId)을 이 스레드에 붙여 주세요. 제가 `firebase-config.js`에 넣어 배포할게요. 이 값은 공개돼도 괜찮아요.

사용법: 한 사람이 설정 > 가족 공유 > "가족 만들기"를 누르면 10자리 초대코드가 나와요. 배우자 휴대폰에서 그 코드를 입력하면 기록이 같이 보여요.

### 3. App Store 앱(네이티브)으로 가려면

- Apple 개발자 계정 연 $99가 필요해요. TestFlight 배포도 이 계정이 있어야 해요.
- Mac이 없으므로 클라우드 빌드(Codemagic 무료 구간, 매달 macOS 빌드 시간 제공)로 빌드해서 TestFlight로 아이폰에 받아요. 빌드와 서명은 클라우드가 하고, Apple 개발자 계정만 연결하면 돼요.
- Mac 없이 무료 Apple ID만으로 내 폰에 직접 설치하는 방법은 사실상 없어요. 그래서 개발자 계정을 만들기 전까지는 이 웹앱으로 테스트해요.
- 위젯, Siri 음성 기록, 앱 알림은 네이티브 앱에서만 제대로 돼요. 이 웹앱으로는 안 돼요.

## 웹앱의 한계 (아이폰)

- 위젯, Siri, 잠금화면 표시는 안 돼요.
- 배우자가 기록했을 때 오는 푸시 알림은 안 돼요 (0원 구조에서는 알림을 보낼 서버가 없어요). 앱을 열면 최신 기록으로 맞춰져요.
- 기록은 휴대폰 안에 저장돼요. 홈 화면 앱은 Safari가 임의로 지우지 않지만, 휴대폰을 바꾸기 전에는 설정 > 백업 파일 저장을 해 두세요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면, 기록, 통계, 내보내기, 백업) |
| `who_lms.js` | WHO 성장 기준표 (0~24개월, 성장곡선과 백분위 계산용) |
| `sync.js` | 가족 공유 (Firebase 설정이 있을 때만 불러옴) |
| `firebase-config.js` | Firebase 설정값. 비어 있으면 가족 공유가 꺼짐 |
| `firestore.rules` | Firestore 보안 규칙 (초대코드를 아는 가족만 읽고 쓰기) |
| `sw.js` | 오프라인 실행용. 파일을 바꾸면 안의 VERSION을 올려야 함 |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘과 앱 이름 |
