# 아기로그 안드로이드 앱 (갤럭시 테스트용)

아이폰에서 쓰는 웹앱(https://leecornell0131-ux.github.io/babylog/)을 앱 안에 그대로 띄우고, 안드로이드에서만 되는 기능을 덧붙인 앱이에요.

- **화면과 기록 기능은 웹앱과 100% 같아요.** 웹앱을 고치면 이 앱도 다시 설치하지 않고 다음에 열 때 같이 바뀌어요.
- **가족 공유(초대코드)도 웹앱 코드 그대로**라 아이폰 웹앱과 기록이 합쳐져요. Firebase 설정도 웹앱의 `firebase-config.js` 하나만 채우면 돼요.
- 안드로이드에서만 되는 것
  - 잠금화면·알림창 타이머: 수면이 진행 중이면 시간이 흘러가는 알림이 뜨고, "깼어요" 버튼으로 바로 끝내요. 진행 중 수유(웹앱이 `end: null`인 수유 기록을 지원하면)도 같은 방식으로 떠요. Android 16(One UI 8) 이상에서는 실시간 정보(Live Updates)로 올려 달라고 요청해요.
  - 홈 화면 위젯: 마지막 수유 후 지난 시간이 계속 흘러가고, 수유·소변·대변·수면 버튼이 있어요. 버튼을 누르면 앱이 열리면서 바로 기록되고 가족 공유로 올라가요.
  - 배우자 기록 바로 반영: 다른 휴대폰에서 기록하면 알림 서버(`push-server/`, Cloudflare 무료)가 푸시를 보내 위젯·잠금화면 타이머가 몇 초 안에 바뀌어요. 푸시가 늦을 때를 대비해 15분마다도 확인해요. 서버 설정은 `push-config.json`(배포 워크플로가 만듦)을 인터넷에서 읽어서, 서버를 올려도 APK를 다시 설치할 필요가 없어요.
  - 새 버전 알림: 안드로이드 쪽(위젯·알림)이 바뀐 새 APK가 나오면 앱을 열 때 "새 버전이 있어요"가 떠요.
- 운영비 0원: Google Play($25)에 올리지 않고 APK를 직접 설치해요. 빌드는 공개 저장소의 GitHub Actions(무료)가 해요.

## 설치하기 (갤럭시)

1. 갤럭시에서 이 주소를 열어요: https://github.com/leecornell0131-ux/babylog/releases/latest/download/babylog.apk
2. 내려받은 `babylog.apk`를 열어요. "출처를 알 수 없는 앱" 허용을 물으면 이 브라우저(Chrome 또는 삼성 인터넷)에 허용해요.
3. Play 프로텍트가 "확인되지 않은 앱"이라고 하면 "그래도 설치"를 눌러요. 스토어에 올리지 않은 테스트 앱이라 뜨는 안내예요.
4. 처음 열 때 인터넷이 필요해요. 위젯 추가와 알림 허용을 물으면 허용해요.

새 버전도 같은 주소에서 받아 덮어 설치하면 돼요. 기록은 그대로 남아요.

## 웹앱과 연결되는 지점 (웹앱을 고칠 때 지켜야 할 것)

이 앱은 웹앱을 고치지 않고 `app/src/main/assets/bridge.js`를 페이지에 넣어서 아래만 씁니다. 이름이 바뀌면 위젯·알림이 멈추니 같이 고쳐야 해요.

| 웹앱 쪽 | 쓰는 곳 |
|---|---|
| `localStorage['babylog-v1']` 저장 | 저장될 때마다 알림·위젯 갱신 |
| 기록 형식: 진행 중 수면 = `type:'sleep', end:null` | 잠금화면 수면 타이머 |
| 진행 중 수유 = `type:'feed', end:null` (웹앱에 아직 없음) | 잠금화면 수유 타이머 |
| `window.BabyApp.state / applyRemote / toast / refresh` | 위젯 버튼 기록 |
| `window.BabySync.local(state)` | 위젯으로 넣은 기록을 가족에 올리기 |
| `#bFeed` 버튼, `#sheetRoot` | 위젯 수유 버튼, 뒤로 가기로 입력 창 닫기 |
| `navigator.share`, `navigator.clipboard` | 안드로이드 공유 창·복사로 대신함 (백업 파일 저장, 초대코드 복사) |

## 빌드

`android-app/` 아래나 워크플로가 바뀌어 저장소에 올라가면 `.github/workflows/android.yml`이 APK를 만들어 릴리스(`android-빌드번호`)로 올려요. 빌드 번호가 앱 버전 번호예요.

`app/babylog-test.jks`는 테스트용 서명 키예요. 같은 키로 서명해야 덮어 설치가 돼서 저장소에 넣어 뒀어요. 공개돼 있으니 Play 스토어에 낼 때는 비공개 키를 새로 만들어야 해요.
