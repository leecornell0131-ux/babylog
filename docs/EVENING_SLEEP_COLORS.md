# 수면 시간 색상 변경 / Claude 인계 (2026-10-20)

사용자가 기존 웹서비스에 적용하도록 명시적으로 요청했다. 기준 main은 48e3a87. 서버 사용량 개선 Draft PR #13과 독립적인 변경이다. Firebase/Worker/Android APK/기록 형식은 수정하지 않는다.

## 동작

- 선택한 날짜의 기기 현지시각 밤 8시 전: 기존 보라색. 밤 8시부터 참고 범위에 따라 시간 숫자만 초록/노랑.
- 오늘이 바뀌면 새 날짜는 다시 보라색. 과거 날짜는 밤 8시를 지났으므로 색상 표시 가능.
- 기존 매분 화면 갱신/화면 복귀/기록 변경 때 계산. 추가 타이머, 서버 조회, 쓰기 없음.
- 화면 첫 항목은 '수면 합계'(지난밤+오늘 낮잠)로 명확히 표시하고 밤잠을 아래에 유지. 24시간 총수면 기준을 밤잠 단독에 잘못 적용하지 않는다.
- 낮잠 합계, 최근 한 번의 깨시도 색상 표시. 하루 전체 깨시는 한 번의 깨시 기준과 다르므로 보라색 유지.
- '정상/비정상/경고' 등 평가 문구나 알림을 추가하지 않음. 기본 '기준 보기'와 기존 참고표는 유지.
- 기존 sleep_rules.js의 월령별 참고값 재사용. 조산/예정일 기준은 기존 sleepRef 그대로. 새로운 의학적 기준을 만들거나 참고값의 정확성을 새로 검증한 변경은 아님.
- 밤잠/완료된 낮잠 기록이 없거나, 미완료·겹침·8시간 이상 설명 안 되는 공백·표시된 기록 누락이 있으면 보라색 유지. 기록 완전성을 자동으로 100% 알 수 있다는 의미는 아니다.
- 진행 중 짧은 깨시는 아직 끝나지 않았으므로 짧다는 이유로 노랑 처리하지 않는다.

## 검증

Node 테스트: `node --test tests/sleep-colors.test.cjs`. 시각 경계/범위 경계/누락/날짜 변경/실제 카드 통합/겹침을 확인. 브라우저 390px 폭에서 19:59 보라, 20:00 초록 및 노랑 예시를 실제 렌더한 뒤 검토.

`design/evening-sleep-colors.html`은 실제 카드 HTML로 만든 정적 예시이며 실제 아이 기록이 아니다. 원본 데이터/가족코드/비밀값을 넣지 않음.

## 버전과 호환

PWA 0.3.24, sw.js와 화면 버전 일치. sleep-colors.js도 오프라인 cache에 포함. babylog-v1/BabyApp/BabySync.local/end:null 및 모든 저장 형식 그대로이므로 구버전 갤럭시와 혼용 가능. 웹 화면 기능이므로 APK 업데이트 불필요.

Draft PR #13은 아직 미적용이며 그 브랜치의 0.3.23을 나중에 병합할 때 이 UI/버전을 덮지 않도록 최신 main으로 갱신 후 다음 버전으로 올려야 한다.

기존 복구 태그 backup/main-before-sync-optimization-2026-10-20도 동일 기준 main을 가리킨다. 롤백할 때 원본 기록을 지우지 말고 웹 코드만 되돌린 뒤 SW 버전을 새 번호로 올린다.
